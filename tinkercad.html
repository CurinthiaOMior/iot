Sistema de iluminação

Controle de iluminação automatizado com sensor PIR (movimento) e LDR (luminosidade): o LED só acende quando há alguém presente e o ambiente está escuro.

Movimento→Luminosidade→Decisão→LED
Sensores
PIR (digital) · LDR (analógico)
Saída
LED no pino 13
Regra
Movimento detectado e leitura do LDR abaixo de 500
main.ino
int pirPin = 2;
int ldrPin = A0;
int ledPin = 13;

void setup() {
  pinMode(pirPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int movement = digitalRead(pirPin);
  int light = analogRead(ldrPin);

  if(movement == HIGH && light < 500) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

Sistema de distância

Medição de distância com sensor ultrassônico e calibração por potenciômetro, para ajustar a sensibilidade do alerta.

0 cm50 cm100 cm+
Sensores
HC-SR04 (Trigger/Echo) · potenciômetro
Cálculo
tempo do eco × 0,034 ÷ 2, em centímetros
Limiar
ajustável de 10 a 200 cm pelo potenciômetro
distance.ino
const int trigPin = 9;
const int echoPin = 10;
const int potPin = A1;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;
  int threshold = map(analogRead(potPin), 0, 1023, 10, 200);

  Serial.println(distance);
}

Sistema ambiental

Monitoramento contínuo de temperatura e umidade, com atuadores para regular o microclima.

24 °CTemperatura
60 %Umidade
IdealCondição
Sensor
DHT11 no pino 4 (digital, 1 fio)
Leitura
a cada 2 segundos, pelo Monitor Serial
Erro
se a leitura falhar, imprime “Erro sensor”
environment.ino
#include <DHT.h>
#define DHTPIN 4
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float h = dht.readHumidity();
  float t = dht.readTemperature();

  if (isnan(h) || isnan(t)) {
    Serial.println("Erro sensor");
    return;
  }

  Serial.print("Umid: ");
  Serial.print(h);
  Serial.print("% Temp: ");
  Serial.print(t);
  Serial.println("C");
  delay(2000);
}
